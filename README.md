# PORTER COFFEE 장부

장부(선결제) 고객의 남은 금액을 빠르게 찾고, 메뉴를 누르면 바로 차감되는 카페용 앱입니다.

- 이름·초성 검색 (예: `ㄱㅁㅅ` → 김민수)
- 메뉴 버튼으로 즉시 차감, 옵션(테이크아웃 −500, 디카페인·오트 밀크 +500)
- 충전 시 10% 적립, 기록별 삭제, 일별 내역
- 엑셀 불러오기 / 내려받기
- 휴대폰·태블릿·PC에 앱으로 설치 (PWA), 인터넷이 잠깐 끊겨도 동작

데이터는 Firebase(Firestore)에 저장되며, `firestore.rules`에 등록한 카페 계정으로 로그인해야만 볼 수 있습니다.
설정 방법은 `설치 안내.txt`를 참고하세요.
